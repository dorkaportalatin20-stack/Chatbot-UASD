## 📖 Descripción General
Aplicación web tipo chatbot que permite realizar consultas en lenguaje natural sobre el contenido del **Estatuto Orgánico de la Universidad Autónoma de Santo Domingo (UASD)**. El sistema responde de forma clara y fundamentada utilizando únicamente la información contenida en el documento oficial.
